# VFX Mesh Generator

VFX 特效面片程序化生成工具（Unity Editor 扩展）。

## 功能
- 8 种 Mesh 类型：Plane / Ring / Cross / Sphere / Helix / Spline / GhostTrail 刀光 / Custom 自定义多边形
- 顶点色渐变（UV 渐变 + 高度渐变）
- 双套 UV（UV1 / UV2 各自独立 Rotate、Tiling、翻转、UV 模式），Tiling 上限可自定义
- UV 模式：矩形 / 圆形 / 极坐标（Plane、Ring、Custom）
- 全局 Noise 形变（噪声贴图偏移顶点，5 种方向 + UV/高度遮罩）
- 独立 UV 预览窗口（UV1/UV2 切换 + 贴图背景 + 缩放平移）
- 预览专用（不烘焙进模型）：流速滚动、预览平铺、平铺缩略图、剔除背面
- Custom：边界控制点起伏（MVC 高度插值）+ 随边界跟随的高度控制点 + 可调不规则边缘
- Spline：多条独立路径合并为一个 Mesh；控制点位置数值可选 Local / World Position；全部样条数据可保存并读取继续编辑
- Spline / Custom 控制点编辑：移动 / 旋转 / 缩放 × 世界 / 本地轴向，框选、软选、Shift 插点
- Helix：沿 Y 高度的整体 XZ 轮廓缩放曲线，可收细腰部
- 各含十字面片的类型（Ring / Helix / Spline / GhostTrail / Cross）可单独控制新增十字面的宽度
- 轴点自由偏移、法线翻转
- FBX 导出（含 UV2 / 顶点色；可存到工程内或桌面）
- 破碎初版：导入 MeshFilter 或 Mesh 资源，将相邻三角面分成碎片、补厚度与侧壁，导出为带独立节点的 FBX
- 模块化地刺：形状、排列、生长时序独立设置；预览错峰生长，导出最终模型和带节点 Y 缩放动画的 FBX

## 使用
菜单 `Tools > VFX Mesh Generator`（快捷键 Alt+Ctrl+U）

UV 预览窗口：`Tools > VFX UV Viewer`，或主面板 UV 设置里的「打开 UV 预览窗口」。

## v1.9.0 样条数据保存与读取

在主窗口选择 **Spline**，使用参数区顶部的「保存样条数据」和「读取样条数据」。

1. 完成控制点、路径和形状设置后，点击「保存样条数据」，选择保存位置，得到一个 `.json` 文件。
2. 之后打开工具，选择 Spline 并点击「读取样条数据」，选中之前保存的文件。
3. 全部路径和设置恢复后，可继续移动控制点、调整宽度曲线、增删路径，再保存同一文件或另存一个新样式。

数据包含全部路径的本地控制点与翻转角、当前路径、条带／十字／管状形态、细分、宽度、扭曲、带权重的曲线、点工具与 Local/World 显示方式、软选、UV1/UV2、Noise、顶点色、法线／轴点，以及预览模型位置／旋转／缩放和预览设置。读取后会显示预览并清空之前的选点状态。

贴图和材质以工程资源 GUID、资源路径和子资源标识记录。资源在同一工程内移动后仍可通过 GUID 找到；跨工程使用时需将对应资源一起迁移。资源缺失会提示重新指定；尚未保存为工程资源的贴图／材质会提示先保存资源。

「读取样条数据」会替换当前 Spline 路径及上述设置，当前编辑内容需要保留时请先保存。损坏、格式不符或版本不兼容的文件会被拒绝，当前编辑数据保留。样条数据与导出的 Mesh/FBX 分别保存；已导出的 Mesh/FBX 不含可恢复的控制点编辑数据。

通过 Unity Package Manager 的 **Add package from disk** 选择本版本的 `package.json`。已有相同包名时将依赖指向此版本目录；采用脚本复制安装时替换工程中的旧工具脚本，并一并放入新增的 `VFXMeshGeneratorWindow.SplinePresets.cs`。各历史版本保留在独立 Releases 目录内。

## v1.6.0 使用提示

- **Spline 多路径**：选 Spline 后按「+ 新增 Spline」复制并错开当前路径；下拉框或点击蓝色控制点切换路径。所有路径使用同一形态和宽度设置，保存/导出时合并成一个 Mesh。
- **Spline 坐标切换**：「坐标空间」决定操纵轴朝向；「点位置坐标系」决定选中点数值框显示 Local Position 或 World Position。切换显示方式不会移动点。
- **Helix 腰部**：「沿 Y 轮廓缩放」横轴从底部到顶部，纵轴为整个 XZ 截面的倍数。中点设 0.5 可将腰部收至一半；默认曲线全为 1。
- **Custom 高度点**：开启「边界高度插值」后，面内高度点的位置以边界曲面为基准。边界 Y 抬升时高度点会跟随，面板中的高度仍是相对高度。
- **Custom 不规则边缘**：开启后调「边缘起伏幅度」「每边细分数」「起伏频率」「随机种子」。绿色控制点是固定锚点，蓝色线为实际生成边缘；幅度过大导致自交时工具会自动降低扰动。

## v1.7.0 破碎工具

菜单 Tools > VFX Fracture，或在主窗口点击「打开破碎工具」。

1. 拖入场景 MeshFilter，或直接拖入 Mesh 资源；两者同时设置时优先使用 Mesh 资源。
2. 调碎片数量、厚度和随机种子，点击「生成碎片」。拖动「预览散开」检查分片，散开量仅用于预览。
3. 点击「导出 FBX」。一个文件包含全部碎片，每块有独立节点、中心轴点、UV、法线和顶点色；文件保留源模型本地坐标。

初版按网格相邻三角面分组并补背面/侧壁，适合特效表面碎片和薄片模型。对厚壁、凹体和带重复顶点接缝的模型，碎片不是精确体积切割；可先用作效果设计与动效预览。

## v1.8.0 地刺工具

菜单 Tools > VFX Ground Spike，或在主窗口点击「打开地刺工具」。需要安装 Unity FBX Exporter；包依赖已声明为目标工程使用的 `com.unity.formats.fbx@2.0.3-preview.3`。

1. 在「形状模块」选择锥刺、晶刺、刃刺或混合，设置宽、厚、高和随机幅度。
2. 在「排列模块」选择直线、圆环或弧形，设置数量、间距／半径、扰动和随机种子。
3. 在「生长时序模块」设置单根时长、错峰间隔、顺序和曲线。点击「生成 / 刷新地刺」，拖动时间查看。
4. 「导出最终模型 FBX」生成独立节点组成的静态模型；「导出生长动画 FBX」给每根地刺烘焙 Y 缩放关键帧。两种文件都在同一 FBX 中保留每根地刺的独立网格节点。

生长动画使用节点变换，不是骨骼或逐顶点缓存；导入 DCC 时选择保留层级及变换动画。Unity 编辑器预览根部固定，时间起点的 Y 缩放为 0.001。
