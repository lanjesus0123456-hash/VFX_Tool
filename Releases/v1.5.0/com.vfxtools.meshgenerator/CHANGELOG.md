# Changelog

## [1.5.0] - 2026-07-30
六项迭代：Custom 边界高度起伏（修复面片恒为平面）、控制点旋转/缩放、控制点世界·本地坐标、UV 平铺预览（全类型）、Spline 宽度可自定义上限、各十字面片类型新增十字面宽度。

### Fixed —— Custom 边界控制点的 Y 被完全忽略（面片恒为平面）
- 症状：Scene 里把边界控制点沿 Y 上下拖动，只有线框跟着动，生成的面片始终是一张平面。
- 原因：三角剖分只在 XZ 平面进行（`poly2D` 只取 x/z，`TriangulatePieceXZ` 一律写 `y = 0`），边界点的 Y 从未参与生成。
- 修复：新增「边界高度插值」——用均值坐标（Mean Value Coordinates, MVC）把各边界点的 Y 平滑插值到面内每一个顶点：
  - 顶点落在某个边界点上 → 直接取该点高度；
  - 顶点落在某条边界边上 → 沿该边线性插值（裁剪产生的所有边缘点都走这一支，故边缘严丝合缝、无台阶）；
  - 顶点在面内 → 按 MVC 权重混合全部边界点高度，凹多边形同样成立。
- 「填充密度」同时决定高度过渡的平滑度（密度越高插值越顺）；开关「边界高度插值」可退回旧的强制平面行为。
- Shift+左键 插入的新边界点，Y 沿所在边插值（原先被压回 y=0，会在起伏的面上戳出一个坑）；插点的就近判定也改为只比 XZ 距离，边界抬高后仍能正常插点。
- 新增「边界高度归零（压平）」按钮。
- 顺带修复：高度控制点的「高度 / 影响半径」滑条原先硬编码 ±5 / 0.1~10，Scene 里拖超范围会被面板默默夹回 → 改为可自定义上限，并在拖超时自动抬高上限。
- 高度控制点的粉色影响圆环改画在「实际基准高度」上（边界抬升后基准面不再是 y=0）。

### Added —— 控制点旋转 / 缩放（Spline + Custom）
- Spline / Custom 面板新增「控制点工具」：移动 / 旋转 / 缩放三选一，均绕选集质心操作（原先只有移动）。
- 三种工具都支持软选衰减：移动按权重缩放位移、旋转按权重 Slerp 角度、缩放按权重靠向 1。
- 世界坐标模式下一次拖拽结束后 Gizmo 姿态复位（旋转回世界轴向、缩放回 1.0）。
- 注：Spline 的「P{n} 翻转」仍是该点截面的扭转角，与这里的控制点旋转是两件事。

### Added —— 控制点世界坐标 / 本地坐标（Spline + Custom）
- 新增「坐标空间」切换：世界坐标 = Gizmo 轴向对齐世界轴；本地坐标 = 对齐预览模型自身朝向（预览模型被旋转后尤其有用）。
- 选中控制点后，面板同时给出「本地坐标」与「世界坐标」两组 Vector3 数值框，均可双向输入精确定位（Spline 控制点 / Custom 边界点 / Custom 高度点都有）。

### Added —— UV Tiling 预览（所有面片类型通用）
- UV 设置新增「预览平铺 U/V」（UV1/UV2 各一套）：与 Noise 的 UV 平铺一样自由输入、无上限，只作用于 Scene 预览与面板缩略图，**不烘焙进模型 UV**。
- UV 设置新增「显示平铺预览」缩略图：按「Tiling × 预览平铺」铺贴预览贴图（未指定贴图时用棋盘格），偏移跟随「预览流速」一起滚动，与预览 Shader 的采样完全一致。缩略图不含 UV Rotate（会在标签里提示）。
- 预览 Shader（`Hidden/VFXMeshGen_TwoSide`）新增 `_PreviewTile`，采样改为 `uv * _PreviewTile + _Scroll`。
- U/V Tiling、UV2 U/V Tiling 四个滑条上限从硬编码 10 改为可自定义（共用一个 max 输入框），最小值 0.1 → 0.01。

### Added —— 自定义滑条上限（通用控件）
- 新增 `SliderWithMax`：滑条右侧带一个「max」输入框，上限随时可改；上限调小时会把当前值一起夹回范围，不会留下滑条外的隐形数值。

### Changed —— Spline 宽度上限可自定义
- Spline「宽度」/「管半径(宽度)」原先硬编码最大 5（对大范围特效不够用）→ 改用 `SliderWithMax`，上限自定义。

### Added —— 十字面宽度（各含十字面片功能的类型）
开启十字面片后，可单独控制**新增的那片十字面**的宽度，取值为主面宽度的倍数（1 = 与主面等宽，故默认行为与旧版逐顶点一致），每个滑条的上限都可自定义：
- Ring「是否为十字片」→「十字面宽度(×)」（1 = 与环面斜边等宽）
- Helix「是否为十字片」→「十字面宽度(×)」
- Spline 形态=十字 →「十字面宽度(×)」（只作用于第二片）
- GhostTrail「十字面片」→「十字面宽度(×)」
- Cross 类型 →「十字面宽度(×)」（作用于第 2 片起新增的那些片，第 1 片不变）

### 验证
- 用目标工程实际使用的 Unity 2020.3.26f1 引用集 + Roslyn 编译：0 error，警告与 v1.4.0 完全一致（4 条历史遗留的未使用字段）。
- MVC 边界高度插值独立数值测试全通过：顶点命中、边上线性插值、正方形中心对称权重(=1/4)、三角形内退化为重心坐标、边界全平时处处为 0（旧行为不变）、凹多边形无 NaN。
- 已知特性：凹多边形的 MVC 权重可为负，面内高度可能轻微超出边界给定的高低区间（实测 [-0.5,1] → [-0.72,1]），这是 MVC 的固有性质，曲面仍平滑连续。

## [1.4.0] - 2026-07-07
大版本更新：Custom 三角剖分重写 + 立体高度雕刻、Noise 全面修复与增强、极坐标 UV（Plane/Ring/Custom）、Plane 扭曲带动 UV、预览流速与背面剔除。

### Added —— Custom 立体高度控制
- Custom 面内可添加「高度控制点」（本地位置 + 高度 + 影响半径 + 衰减曲线），Scene 中三轴 Gizmo 拖拽即可上下抬升/下压，把平面雕成立体面（类似轻量重拓扑）。
- 高度点独立于三角剖分密度与边界，改密度/改边界不丢失雕刻；粉色圆环显示影响范围，虚线显示抬升量。

### Added —— 极坐标 UV（Plane / Ring / Custom）
- UV 模式新增「极坐标」：U = 绕中心角度(0-1)，V = 归一化半径(0-1)，适合旋涡/冲击波/传送门/流光等径向效果。
- 修复极坐标两处天生问题：① ±180° 环绕缝；② 中心奇点。对跨接缝/触及中心的三角形复制顶点、独享 UV 并解算一致角度，接缝收窄为一条线、中心收成干净扇心。
- Custom 流动方向新增「极坐标」（以多边形重心为中心）。

### Added —— Plane 扭曲带动 UV
- Plane 极坐标 UV 改用「扭曲前的原始网格」算角度，几何扭曲时贴图随之拧成螺旋 —— 配合 V 向预览流速可做「流光从边缘沿螺旋流向中心」。

### Added —— 预览增强
- UV 设置新增「预览流速 U/V」（UV1/UV2 各一套）：仅在 Scene 预览滚动 UV 观察流动，不烘焙进模型。
- UV 设置新增「预览剔除背面」开关：Noise/高度形变造成翻折露出背面时可隐藏（预览材质 `Cull [_Cull]`）。

### Changed —— Custom 补面算法重写
- 边缘填充从「网格角点采样」（边缘有锯齿空腔）重写为「逐单元 Sutherland-Hodgman 裁剪 + 耳切三角化」，顶点精确落在多边形真实边界，彻底消除边缘缝隙。
- 新增顶点焊接（按 XZ 位置合并单元交界重复点），消除法线断裂 —— 叠加 Noise/高度形变不再开裂。

### Changed —— Noise 增强
- 「UV 缩放」单值 → 「UV 平铺(Tiling) + UV 偏移(Offset)」U/V 独立。
- 强度遮罩与顶点色**解耦**：独立的「UV 渐变遮罩」+「高度渐变遮罩（曲线值即遮罩 0~1）」，不再依赖 mesh.colors。

### Fixed
- Noise 采样只取到贴图左上角（未乘贴图尺寸）→ 改为按贴图宽高映射 + 双线性采样，整张噪声图正确铺满。
- Noise 噪声贴图不再要求开启 Read/Write：不可读时用 Blit→临时 RenderTexture→ReadPixels 读取，项目任意贴图可直接使用。
- Noise 高度渐变遮罩失效（原读顶点色 alpha 恒为 1）→ 独立曲线遮罩，真正生效。

### Removed
- 移除 Plane「圆形」UV 模式（对平面无意义，仅保留 矩形 / 极坐标；Ring 圆形保留）。
- 移除 Custom「U Tiling」（与 UV 设置里的 Tiling 重复）。


## [1.3.0] - 2026-07-06
大版本更新：4 项新功能 —— Plane 圆形 UV、Ring 龙卷风模式、全局 Noise 形变、Custom 自定义多边形模型。

### Added —— Plane 圆形 UV 模式
- Plane 面片新增「矩形 / 圆形」UV 模式（UV1/UV2 独立），与 Ring 对称。
- 圆形 UV 采用极坐标投影：顶点 XZ 坐标按较大边归一化映射到 0-1 圆盘，光圈/光晕等圆形贴图不变形。

### Added —— Ring 龙卷风模式
- Ring 新增「半径曲线（上→下）」AnimationCurve：对 Lerp(topR, botR, t) 的结果乘以曲线权重，可做中间膨胀/收窄的龙卷风轮廓。
- Ring 新增「高度曲线（上→下）」AnimationCurve：非线性分布高度，龙卷风的"腰"可自由调节。
- Ring 新增「倾斜 X / 倾斜 Z」滑条（-45~45°）：整体绕 X/Z 轴旋转，龙卷风歪斜效果。
- RingCircularUV 改为按实际顶点最大距离归一化，兼容半径曲线放大效果。
- 十字片端点同步使用曲线预计算值，保持一致。

### Added —— Noise 顶点偏移（全局）
- 新增「Noise 形变」折叠区，对所有面片类型生效。
- 支持拖入噪声贴图，按 UV 采样（Wrap 模式），沿指定方向偏移顶点。
- 偏移方向：法线 / X / Y / Z / 自定义向量，共 5 种。
- 参数：偏移强度（0~2）、UV 缩放（0.1~10）、顶点色 Alpha 遮罩开关。
- 噪声像素缓存（贴图未变时复用），不可读贴图自动警告。

### Added —— Custom 自定义多边形模型（第 8 种 Mesh 类型）
- 新增 MeshType.Custom：用户在 Scene 视图中放置边界控制点，自动 Ear Clipping 三角剖分填充内部面。
- Scene 交互复用 Spline 控制点系统：左键选中/拖拽、Shift+左键插入、矩形框选、多点整体移动、软选（半径+衰减曲线）。
- 边界细分（1~20 段）：每条边等分插值，增加面数密度。
- UV 流动方向：世界 X / 世界 Z / 本地 X / 本地 Z / 包围盒（自动取最长轴），配合 U Tiling 做贴图流动效果。
- UV 翻转开关。Inspector 提供「+ 添加点 / - 删除选中点 / 重置为矩形」按钮。
- Custom 模式与 Plane/Spline 一样默认不翻转正反面。

### Changed
- MeshType 枚举新增 Custom（第 8 种）。
- ApplyUV 重构为支持 Ring 和 Plane 双类型圆形 UV，按各自模式独立选择。
- 正反面翻转判断扩展：Plane / Spline / Custom 三种默认不翻转。
