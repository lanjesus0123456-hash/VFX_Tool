# Changelog

## [1.2.0] - 2026-06-23
新增 GhostTrail（刀光）网格类型 —— 复刻 3ds Max GhostTrail，按武器运动轨迹生成刀光带模型，并经多轮迭代打磨为可实时调参、可平滑、可十字成型的完整工作流。

### Added —— 刀光核心
- **GhostTrail 刀光**（第 7 种 Mesh 类型）：在武器/手上挂标记点，采样其运动连成刀光带网格，走现有 FBX 导出存模型。
- 两种刀光定义：「单点+固定长度」（挂一个点，沿其本地轴 Up/Right/Forward 拉出固定宽度，点随武器朝向旋转）与「两点(上下边)」（宽度取两标记点真实间距）。
- 拉伸轴向（Up / Right / Forward，默认 **Forward**）、轴点对齐（居中 / 端点 / 起始点，默认 **起始点**）。
- Scene 视图实时 Gizmo：在标记点处画出刀光宽度连线与上下端点，直观预览宽度/轴点。

### Added —— 采样方式
- **自动播放并记录**（推荐）：工具自己按帧范围驱动 Director 逐帧走、到结束帧自动停并生成；Scene 视图下方居中也有一个绿色快捷按钮。
- **跟随播放记录**：照常播放特效 timeline，工具跟着每个编辑器帧记录世界坐标；指定 Director 时到结束帧自动停。
- **采样当前帧**：手动逐帧累积（自定义播放取不到 Director 时的兜底）。
- 自动检测场景内 `EffectEditorDirector` 并自动加载（特效场景一般只有这一个）。
- **子帧采样密度**（默认 10）：自动播放时每帧细分多次 Evaluate（dir.time 连续插值），运动过快也平滑不折线，且帧号不变。

### Added —— 形态控制
- **刀光宽度实时生效**：单点数据只存「中心线+单位方向」，宽度在生成时套用，拖宽度即重建，无需重新采样。
- **统一面数(重采样)** + **长度方向段数**：按中心线弧长重采样，统一长度方向面数密度。
- **纵向面数分段**：沿刀光宽度方向细分面数。
- **平滑路径**（独立于重采样）：拉普拉斯平滑只作用于中心线、保持每个截面宽度不缩小；平滑强度可调，且**强度最大值可自定义**。
- **十字面片**：再生成一片绕中心线切线旋转 90° 的带，与主片组成十字截面，刀光更有体积。

### Added —— 导出
- **导出时保持世界位置**开关：预览始终画在武器真实挥砍位置便于核对；导出时按此开关决定保持世界坐标或重定心到原点（默认重定心）。
- 采样诊断日志：打印路径世界包围盒尺寸，尺寸≈0 提示未采到运动。

### Added —— UV（通用）
- UV1、UV2 各新增 **U / V 翻转**开关（在 0–1 基础上先翻转再做 Tiling/Rotate）。

### Changed / Fixed
- 修复刀光法线朝向（之前朝内，现与其它面片一致朝外，可再用「翻转正反面」切换）。
- 修复起始帧/结束帧污染：录制采用「先播放后采样」预热 + 停止时先结束采样再延迟还原播放位置，首尾帧不再被编辑态姿势污染。
- 界面精简：采样密度、纵向面数分段、平滑路径、十字面片等收进「更多设置」折叠；主面板只留常用项。

## [1.1.0] - 2026-06-12
大版本更新：UV 工作流可视化 + UV2 真正可用 + 全面中文化与界面精简。
### Added
- **UV 预览窗口**（独立可停靠 `VFXUVViewerWindow`，菜单 `Tools ▸ VFX UV Viewer` 或主窗口「打开 UV 预览窗口」）：实时绘制当前网格的 UV 三角线框 + 贴图/棋盘格背景 + 0–1 边界 + 0.25 细分网格；UV1/UV2 切换、贴图/线框/网格开关、滚轮缩放、拖拽平移、一键适配。
- **UV2 独立 UV 模式**：UV1/UV2 各自可选「矩形 / 圆形」（Ring 圆形映射改为按通道在 ApplyUV 计算，新增 RingCircularUV），UV2 默认圆形，使其真正区别于 UV1。
- **预览模型同步 UV 通道**：在 UV 预览窗口切 UV1/UV2 时，场景预览模型贴图按对应通道（shader 新增 `_UVChannel`，读 TEXCOORD0/1）同步显示；关闭窗口自动恢复 UV1。
### Changed
- Ring「UV 模式」从 Ring 参数区移入「UV 设置」折叠区（仅 Ring 显示）。
- UV 模式移除「Auto」，仅保留两种并中文化为「矩形 / 圆形」。
- Spline「形态」选项中文化：条带 / 十字 / 管状（面向全员使用）。
- 界面精简：顶部预览模型 Transform(TRS) 改为可折叠、默认收起；原「翻转正反面 + 轴点偏移」栏更名「法线 / 轴点」并默认收起。

## [1.0.4] - 2026-06-12
### Fixed
- Ring「UV 模式」下拉（Auto / Rect / Circular）恢复显示：此前 `ringUVMode` 字段与 BuildRing 逻辑都在，但面板漏画了下拉控件，导致无法选择。已在 Ring 参数区补回。
- Spline 矩形框选不再卡死：起框时抢占 `GUIUtility.hotControl` 并消费事件，避免 MouseUp 被 SceneView 默认工具吞掉导致框选框一直残留；拖拽/抬起按 hotControl 归属处理，画框块加 hotControl 门槛防鬼影。
### Notes
- 自此采用顺序补丁编号：每次备份 +0.0.1。对应旧语义化编号：1.0.0=v1.0.0、1.0.1=v1.1.0、1.0.2=v1.2.0、1.0.3=v1.3.0。

## [1.3.0] - 2026-06-11
### Added
- 新增第二套 UV（UV2）：可选开关，基于原始 0~1 展开生成，带独立 Rotate / U Tiling / V Tiling，与 UV1 分开调，互不影响
- FBX 导出支持 UV2：写入独立 Layer 1 的 UVSet1（标准多 UV 集做法）
### Changed
- 重构 UV 变换为共享方法 TransformUV，UV1/UV2 复用（DRY）；默认关闭 UV2 时行为与既有版本完全一致

## [1.2.0] - 2026-05-30
### Added
- Helix 新增「头部扭曲 / 尾部扭曲」两个独立角度（-360~360），条带绕路径(tangent)旋转，端点强、中间(t=0.5)平滑过渡到 0
- Spline 新增矩形框选（空白处拖框多选控制点）+ 多点整体移动（拖选集质心 Handle）
- Spline 新增「软选」（开关 + 软选半径 + 衰减曲线），移动选中点时半径内未选点按距离衰减跟随
- 预览新增「隐藏预览」开关（只关 MeshRenderer，不销毁；线框同步隐藏，Spline 控制点 Handle 保留以便继续编辑路径）
