## 1. Custom：边界控制点终于能拉出起伏了（原先恒为平面）

**原来的问题**：Scene 里把绿色边界控制点沿 Y 上下拖，只有线框动，生成的面片永远是一张平面。
原因是三角剖分只在 XZ 平面做，边界点的 Y 从头到尾没参与生成。

**现在怎么用**
1. Mesh Type 选 `Custom`。
2. 面板里确认「**边界高度插值**」是勾选状态（默认勾选；取消勾选 = 回到旧的强制平面行为）。
3. Scene 里点中一个绿色控制点 → 用 Gizmo 的 **Y 轴**往上/往下拖，整片面会跟着起伏。
4. 想要过渡更顺 → 把「**填充密度**」调高（密度同时决定高度插值的平滑度）。
5. 想精确给高度 → 选中点后，面板下方有「**P{n} 本地坐标 / P{n} 世界坐标**」两组数值框，直接输 Y。
6. 想一键压平 → 按「**边界高度归零（压平）**」。

**插值规则**（用的是均值坐标 Mean Value Coordinates）
- 顶点正好在某个边界点上 → 取该点高度。
- 顶点在某条边界边上 → 沿这条边线性插值。裁剪产生的所有边缘顶点都走这一支，所以**边缘不会出台阶/裂缝**。
- 顶点在面内 → 按 MVC 权重混合所有边界点的高度；凹多边形也成立。

**已知特性**：凹多边形的 MVC 权重可以为负，面内高度可能轻微超出你给的高低区间
（实测边界给 [-0.5, 1]，面内出现 -0.72）。这是 MVC 的固有性质，曲面本身仍然平滑连续，不是 bug。
如果不想要这个溢出，把凹角改缓、或改用「立体高度控制」的高度点来雕。

**顺带修的**
- 「立体高度控制」里的「高度」滑条原先写死 ±5、「影响半径」写死 0.1~10。超范围时滑条会**默默把值夹回去**，
  表现就像 Scene 里怎么拖都拖不上去 → 现在两个滑条右侧都有可改的 `max`，而且检测到实际值超上限时会自动抬高上限。
- 高度点的粉色影响圆环，现在画在**实际基准高度**上（边界抬起后基准面不再是 y=0）。
- Shift+左键在边上插新点时，新点的 Y 沿这条边插值（原先被压回 y=0，会在起伏的面上戳出一个坑）；
  插点的「离哪条边最近」也改成只比 XZ 距离（否则边界抬高后这条边显得很远，插不进去）。

## 2 & 3. Spline / Custom 控制点：旋转、缩放、世界/本地坐标

Spline 和 Custom 面板里都新增了两行开关：

| 控件 | 说明 |
|------|------|
| **控制点工具** | `移动` / `旋转` / `缩放` 三选一。原先只有移动。 |
| **坐标空间** | `世界坐标` = Gizmo 轴向对齐世界轴；`本地坐标` = 对齐预览模型自身朝向。 |

- 三种工具都是**绕选中点的质心**操作。框选多点后旋转/缩放，整组一起变。
- 三种工具都支持「**软选**」衰减：移动按权重缩放位移、旋转按权重插值角度、缩放按权重靠回 1.0。
- 世界坐标模式下，一次拖拽结束后 Gizmo 会复位（旋转回世界轴向、缩放回 1.0），下次从头开始；
  本地坐标模式保留跟随物体的朝向。
- 「本地坐标 / 世界坐标」两组 Vector3 数值框可以双向输入，用来精确定位（Spline 控制点、Custom 边界点、Custom 高度点都有）。

> 区分一下：Spline 的「**P{n} 翻转**」是**该点截面绕路径的扭转角**（影响面片朝向），
> 和这里的「控制点旋转」（旋转点的**位置**）是两件不同的事，两个都还在。

## 4. UV Tiling 预览（所有面片类型通用）

UV 设置折叠栏里（对所有 Mesh Type 生效）：

| 控件 | 会不会烘焙进模型 | 说明 |
|------|------|------|
| `U Tiling` / `V Tiling`（UV2 同） | **会** | 上限不再写死 10，右侧 `max` 可自己改；最小值放宽到 0.01 |
| `预览平铺 U/V`（UV2 同） | **不会** | 和 Noise 的「UV 平铺」一样自由输入、无上限。只作用于 Scene 预览和下面的缩略图 |
| `显示平铺预览` | — | 面板内的平铺缩略图 |

- 缩略图按「**Tiling × 预览平铺**」铺贴「预览贴图」（没指定贴图时用棋盘格），
  偏移跟着「预览流速」一起滚，和 Scene 里预览 Shader 的采样完全一致 —— 不进 Scene 也能先看清平铺密度和流动方向。
- 缩略图**不含 UV Rotate**（GUI 铺贴画不了旋转），有旋转时标签里会提示。
- 打开 UV 预览窗口切到 UV2 时，缩略图和预览材质会一起跟着切到 UV2 的参数。

## 5. Spline 宽度上限可自定义

「宽度」（条带/十字形态）和「管半径(宽度)」（管状形态）原先最大只能到 5。
现在滑条右侧多了一个 `max` 输入框，想要 50 就填 50。

## 6. 十字面宽度（各含十字面片功能的类型）

开启十字面片后，可以单独控制**新增的那一片**的宽度，取值是**主面宽度的倍数**：

| 类型 | 开关 | 新增控件 | `1` 的含义 |
|------|------|----------|-----------|
| Ring | 是否为十字片 | 十字面宽度(×) | 与环面斜边等宽 |
| Helix | 是否为十字片 | 十字面宽度(×) | 与主面等宽 |
| Spline | 形态 = 十字 | 十字面宽度(×) | 与主片等宽（只作用于第二片） |
| GhostTrail | 更多设置 ▸ 十字面片 | 十字面宽度(×) | 与主片等宽 |
| Cross | （本身就是十字） | 十字面宽度(×) | 与第 1 片等宽（作用于第 2 片起，第 1 片不动） |

- **默认值都是 1，所以不动它的话，生成结果和 v1.4.0 逐顶点一致**（升级不会改坏已有资产）。
- 每个滑条右侧的 `max` 都能自己改。
- 用倍数而不是绝对值，是因为这些十字面的基准宽度本来就由主面参数推导（例如 Ring 取环面斜边长度、
  Spline 取宽度曲线在该处的值），绝对值反而对不上主面的粗细变化。

## 附：新增的通用控件

所有「右侧带 max 输入框」的滑条都来自同一个控件 `SliderWithMax(label, value, min, ref max)`。
它做两件事：上限随时可改；上限调小时把当前值一起夹回范围，不会留下滑条外的隐形数值。
